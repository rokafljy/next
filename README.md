# 청년일경험 선발관리 시스템 (커넥팅더닷츠)

2026 청년일경험지원사업 신청자 선발을 위한 **관리자·심사위원 전용** 통합 관리 시스템입니다.
모집 데이터(엑셀/CSV)를 업로드하면 신청자 현황을 분석하고, **서류심사 → 인터뷰 대상 선정 → 인터뷰 심사 → 최종 선발**의 전 과정을 하나의 대시보드에서 관리합니다.

## 실행 방법

별도 빌드·서버가 필요 없는 정적 웹앱입니다.

```bash
# 1) 가장 간단 — 파일을 브라우저로 열기
open index.html              # macOS
xdg-open index.html          # Linux

# 2) 로컬 서버로 실행 (권장)
python3 -m http.server 8080
# → http://localhost:8080 접속
```

> 차트(Chart.js)와 엑셀 파싱(SheetJS), 웹폰트는 CDN에서 로드하므로 최초 실행 시 인터넷 연결이 필요합니다.

## 주요 기능

| 메뉴 | 설명 |
|------|------|
| **대시보드** | KPI(신청·서류·합격·인터뷰·최종), 선발 퍼널, 단계/트랙/점수/학력 분포 차트, 트랙별 진행률, 최근 평가 활동 |
| **신청자 현황** | 전체 명단 — 트랙/단계 필터, 검색, 정렬, 적격요건(개인정보·첨부·이상여부) 표시 |
| **신청자 상세** | 프로필·적격 플래그·단계 진행 스트립, 지원동기/포부/경력 원문, **서류·인터뷰 평가 패널**, 단계 처리 버튼 |
| **서류 심사** | 평가 대상 작업대 · 점수 분포 · **합격선 일괄 적용** |
| **인터뷰 심사** | 서류 합격자 **일괄 승급** · 인터뷰 평가 |
| **최종 선발** | 트랙별 인터뷰 점수 순위 + **쿼터 기반 자동 선발 확정** |
| **데이터 업로드** | .xlsx/.xls/.csv 업로드 → 헤더 자동 탐지 → 미리보기 → 명단 교체 |
| **설정** | 평가 항목(**기본 + 추가**) 편집, 배점·합격선·트랙별 선발 인원 설정 |

## 평가 체계

- **서류 심사**: 지원동기 적합성 / 관련 경력·경험 / 수행계획 구체성 / 성장 가능성 *(기본)* + 서류 충실도 *(추가)*
- **인터뷰 심사**: 직무 이해도 / 의사소통 / 문제해결·창의성 / 성실성·인성 *(기본)* + 조직 적합성·열정 *(추가)*

`설정` 메뉴에서 항목명·배점·설명을 수정하고, **추가 평가 항목**을 자유롭게 신설/삭제할 수 있습니다.

## 데이터 형식

`통합신청자명단` 시트 기준 컬럼을 인식합니다: 통합연번, 트랙구분, 이름, 학력, 학교, 학과,
휴대전화번호, 이메일, 개인정보활용동의여부, 첨부파일유무, 확인내용이상여부, 지원동기,
향후 비전 및 포부(수행계획), 관련 경력(경험) 등. 첫 행에 제목/부제가 있어도 헤더 행을 자동 탐지합니다.

> 평가·단계 진행 데이터는 브라우저 **localStorage**에 저장됩니다(서버 없이 동작). 새 파일 업로드 또는 `설정 → 초기화` 시 교체됩니다.

## 구조

```

assets/js/seed-data.js  # 시드 데이터 (통합신청자명단 48명)

```
