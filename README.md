# KU YOUNG MAKERS 2026 — 참여자 모집 사이트

2026 청년 일경험 지원사업(프로젝트형) 참여자 모집을 위한 원페이지 랜딩 사이트입니다.
빌드 도구 없이 `index.html` 파일 하나로 동작합니다. (CSS·JS 인라인, 외부 의존성 없음)

## 실행

파일을 브라우저로 열면 바로 확인됩니다. GitHub Pages는 저장소 설정에서 브랜치를 지정하면
`index.html`이 루트 문서로 바로 서빙됩니다.

## 확정 후 수정이 필요한 값

일정·링크는 `index.html` 하단 `<script>` 최상단의 **CONFIG 블록 한 곳**에 모여 있습니다.
실제 일정이 확정되면 이 블록만 고치면 D-day 카운터, 모바일 하단 바, 모든 신청 버튼이 함께 갱신됩니다.

```js
const CONFIG = {
  applyUrl : 'https://forms.gle/9Us67tzsysnZRuXa9',   // 자체 신청 폼
  portalUrl: 'https://yw.work24.go.kr/main.do',       // 고용노동부 청년일경험 포털
  openAt   : '2026-08-31T09:00:00+09:00',             // 모집 시작
  closeAt   : '2026-09-13T23:59:59+09:00',            // 모집 마감
  rangeText: '2026. 08. 31 (월) 09:00 — 09. 13 (일) 24:00'
};
```

CONFIG 밖에서 확인이 필요한 값은 다음 두 곳입니다.

| 위치 | 현재 값 | 비고 |
|---|---|---|
| `#overview` A5 프로젝트 기간 | 2026년 10월 ~ 11월 (8주) | 확정 일정으로 교체 |
| `#overview` A6 · `#recruit` W2 · 히어로 통계 | 총 120명 / 30팀 내외 | 2026 기수 규모 확정 시 교체 |

활동수당(60만원), 팀 운영비(240만원), 사전 직무교육 15시간, 문의처(ksmi@konkuk.ac.kr ·
02-450-4248)는 기존 운영 기준 그대로입니다.

## 구성

히어로 → 프로그램 소개 → 사업 개요 → 직무 분야 → 프로젝트 과제 7종 → 진행 프로세스 →
참여 혜택 → 모집 안내 → 신청 절차·방법 → FAQ·유의사항 → 최종 CTA·문의처

참여기업명은 노출하지 않고 과제 중심으로 구성했습니다. 기업이 확정되면 `#tasks` 섹션의
각 카드에 기업 라벨을 추가하는 방식으로 확장할 수 있습니다.

## 디자인

20대 청년을 주 사용자로 상정한 다크 기반 "설계도(spec sheet) 에디토리얼" 스타일입니다.

- **컬러** — 잉크 블랙 배경 + 애시드 라임(`#D8FF3E`) 단일 액센트. 경고·필수 안내에만 엠버(`#FF4E1F`) 사용
- **타이포그래피** — Pretendard Variable(CDN, 미로드 시 시스템 한글 폰트로 폴백).
  국문 가독성을 위해 전역 `word-break: keep-all` 적용, 본문 행간 1.7~1.85
- **모션** — 스크롤 리빌, 숫자 카운트업, 진행 프로세스 가로 핀 스크롤(데스크톱),
  마그네틱 버튼. `prefers-reduced-motion` 전면 대응
- **반응형** — 390px~1440px+ 검증 완료, 가로 오버플로 0. 모바일에서는 가로 핀 스크롤이
  스냅 캐러셀로 전환되고 하단에 D-day + 신청 고정 바가 노출됩니다
- **접근성** — 시맨틱 랜드마크, 본문 바로가기, 아코디언 `aria-expanded`/`aria-controls`,
  `:focus-visible` 아웃라인
